## 📅 День 2: Логическая схема, таблица адресации и настройка GNS3

**Дата:** 10.11.2026

**Что сделано:**
1. В draw.io нарисована логическая схема сети с Cisco RTR, Cisco SW и пятью виртуальными машинами (WIN, IOT, CTRL, MON, DB).
2. Составлена таблица адресации с разделением на 3 VLAN:
   - VLAN 10 (192.168.10.0/24): Управленческая сеть (WIN)
   - VLAN 20 (192.168.20.0/24): Серверная сеть (CTRL, MON, DB)
   - VLAN 30 (192.168.30.0/24): Сеть IoT (IOT)
3. В GNS3 собрана топология. На Cisco SW созданы VLAN, настроены Access-порты для конечных устройств
4. На всех ВМ РЕД ОС 8 (IOT, CTRL, MON, DB) через NetworkManager настроены статические IP-адреса, маски и шлюзы согласно их VLAN.
5. На Windows Server 2019 (WIN) задан статический IP 192.168.10.10
6. Для выхода виртуальных машин в интернет добавлен узел Cloud в GNS3, соединенный с роутером

**Как проверили:**
1. **Внутренняя связность:** С машины IOT (VLAN 30) успешно пропингован CTRL (VLAN 20) и WIN (VLAN 10). Меж-VLAN маршрутизация работает.
2. **Таблица маршрутизации:** Команда `show ip route` на роутере показывает три напрямую подключенные сети (C).
3. **Статус VLAN:** Команда `show vlan brief` на коммутаторе отображает корректное распределение портов.
4. **Интернет:** На Windows Server (WIN) успешно выполнен `ping 8.8.8.8` и `ping google.com`. Веб-страницы открываются в браузере.

**Результат:**
- Сетевая инфраструктура полностью развернута и настроена.
- Логическая сегментация через VLAN работает корректно.
- Виртуальные машины имеют доступ как друг к другу так и выход в интернет
- Все схемы и таблицы сохранены в репозиторий. Отправлен итоговый коммит второго дня.
